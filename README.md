# Nerune 하네스 커뮤니티

네룬에서 받아 실행할 수 있는 무료 하네스 목록입니다. 첫 항목은 Nerune의 문서 작업 예제입니다.

## 초대 제작자 등록

1. 공개용 지침과 예제를 .nworker 파일로 내보냅니다. 파일의 배포 라이선스를 정합니다.
2. 본인 GitHub 저장소의 버전이 지정된 Release에 파일을 올립니다.
3. Discussions에 패키지 ID, 버전, 게시자, 라이선스, 다운로드 위치, SHA-256, 공개 예제를 제출합니다.
4. 운영자가 앱에서 설치와 재실행을 확인해 목록에 반영합니다. 새 내용은 새 버전에 게시합니다.

개인 대화, 원본 파일, API 키와 인증 설정은 각 PC에서 관리합니다.
